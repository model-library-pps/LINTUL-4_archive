This FORTRAN implementation of LINTUL-4 is an archive model that is not actively maintained. However, we do maintain one single LINTUL version that is implemented in Python ([link](https://github.com/model-library-pps/LINTUL)). This version is capable of simulating potential, water-limited, and water-and-nitrogen limited growth. 

In principle, PPS does not provide support in using archive models. If you nevertheless are interested in this model, you could try to send an e-mail.
